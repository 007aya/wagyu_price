# Git Lesson

## リモートリポジトリとローカルリポジトリとはそれぞれ何でしょうか？
リモートリポジトリは、大本の枝で、みんなの入力した変更点が集まってくる場所で、ローカルリポジトリは、リモートリポジトリから分岐させた派生のリポジトリで、自分が変更、記入する際はローカルリポジトリに、記入して大本であるリモートリポジトリに入力した情報を合わせることで、ほかの人に変に影響しないで変更することができる。


## プッシュとマージの違いは何でしょうか？
プッシュはローカルリポジトリからリモートリポジトリに合流させることで、マージは、他のブランチでの変更点を取り込むことです。


## コミットとプッシュの違い
コミットは、変更点の保存、プッシュは、ローカルからリモートに合流させること。


## コミットのメッセージはどのように書いてあげるのが最適でしょうか？
何をしたのか、わかりやすく正確に書く


## ローカルでマージするフローと、プルリクエストでマージするフローの違いは何でしょうか？
フローの違いは、マージする前にプッシュして承認されてからマージするのがプルリクエスト。


## コンフリクトを起こしてしまった場合、どう対処すべきですか？
先にマージされた変更内容を取り込む
後にマージしようとしている内容を取り込む
どちらも取り込む
